# CocoTools

A small toolbox of Blender extensions, developed and released together from
one repository.

| Extension | What it does |
| --- | --- |
| [CocoPies](CocoPies/README.md) | Build custom pie menus entirely from the addon's own Preferences panel — no code required. |
| [CocoSelections](CocoSelections/README.md) | Store named object selections and restore them later, from the 3D viewport sidebar. |
| [CocoDelete](CocoDelete/README.md) | `X` deletes straight away in mesh and curve edit mode — no delete menu, no confirmation popup. |

## Install

Add this repository to Blender: **Edit ▸ Preferences ▸ Get Extensions ▸**
repositories dropdown **▸ + ▸ Add Remote Repository**, URL:

```
https://mooncoconutz.github.io/CocoTools/index.json
```

Every extension above then shows up as installable/updatable from that one
repository.

See each extension's own README (linked above) for what it does and how to
use it.
