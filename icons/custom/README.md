# Custom icons

Any PNG (or JPG) dropped in here appears under the **Custom** tab of CocoPie's
icon picker, named after the file: `flatten.png` becomes `flatten`.

Square images around 64x64 work best — Blender scales them down to icon size.
A white shape on transparency matches the look of Blender's own icons on a dark
theme, since preview icons are drawn as-is and are not tinted.

**Icons here are replaced when CocoPie is reinstalled.** For your own icons use
the user folder instead, which survives updates and takes priority over this
one when both hold the same filename. The picker prints its exact path when the
Custom tab is empty; it is:

    <Blender config>/scripts/cocopie_icons/
